# SWIFI Network Simulator

**SWIFI** — это симулятор сети с поддержкой экзотических единиц измерения трафика:  
- **ipybyte** = 2⁹⁰ байт  
- **hpybyte** = 1000 × ipybyte  
- **gpybyte** = 10⁶ × ipybyte  

Возможности:
- Асинхронная симуляция узлов с очередями и маршрутизацией
- Поддержка топологий: звезда, mesh (легко переключается)
- Задержки, потери пакетов, ограничение полосы
- Квоты на передачу данных (в ipybyte)
- Веб-интерфейс с графом сети (D3.js) и графиками (Chart.js)
- Отправка тестовых пакетов через веб-интерфейс
- Обновление статистики в реальном времени по WebSocket

## Запуск

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите: `python app.py` (или `uvicorn app:app --reload`)
4. Откройте `http://localhost:8000`

## Настройка топологии

В файле `app.py` в функции `startup()` выберите нужную:
- `create_star_topology` — звезда
- `create_mesh_topology` — полносвязная

Можно менять параметры линков: `delay_ms`, `bandwidth_mbps`, `loss_rate`.

## Единицы трафика

Все значения в веб-интерфейсе отображаются в ipybyte, но внутренний учёт ведётся в байтах.  
Для перевода в hpybyte или gpybyte можно умножить на 1000 или 1 000 000 соответственно.

## Технологии

- FastAPI (бэкенд)
- asyncio (асинхронная симуляция)
- WebSocket (real-time обновления)
- D3.js (граф)
- Chart.js (графики)
